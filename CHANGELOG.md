# Changelog

All notable changes to D&D Manager are documented here.

## [0.1.0] - 2026-09-04

### Added
- Character management system with D&D 5e stats
- Campaign management with sessions, NPCs, quests, and locations
- Battle simulator with initiative, attack rolls, and damage
- Character generator for random character creation
- CLI interface with commands for characters, campaigns, and battles
- Flask web application with templates
- JSON-based data persistence
- Comprehensive documentation

### Features
- Full D&D ability scores and modifiers
- Experience and leveling system
- Skill and proficiency management
- Inventory and equipment system
- Spell and cantrip tracking
- NPC management
- Quest tracking
- Session logging
- Dice rolling mechanics
- Initiative tracking
- Attack resolution

### Testing
- Unit tests for Character class
- Unit tests for Campaign class
- Unit tests for battle mechanics

For future versions, see open issues and pull requests on GitHub.
